### PR description

## Summary

Boss’s markdown viewer splits headed documents into independently rendered sections so `LazyVStack` can defer off-screen work, caches the heading split across ordinary view invalidations, and avoids remounting parsed content when comment or find highlights change.

- The document `ScrollView` hosts a direct-child `LazyVStack` with per-chunk theme modifiers and explicit chrome spacing, preserving lazy instantiation.
- Heading chunks are refreshed only when the source or collapsible-heading configuration changes.
- Comment anchors resolve once against the concatenated chunk projection, then clip onto only the overlapping chunks; the projection is cached separately from highlighted and flashing anchors, so comment flash changes only reassign anchors.
- Whitespace-only clipped anchor fragments are discarded, preventing an ambiguous fragment from highlighting unrelated whitespace.
- Parse timing remains derived from document chunk heights, and highlight refreshes re-parse in place without resetting scroll position.
