- **Project:** Make tmux the only pane hosting mode

- **Verdict: gate NOT met.** Deletion tasks (`Collapse local engine spawn and teardown to tmux only` onward) remain blocked.

## Why this report exists now

This task depends on "Default every local pool to tmux for one rollback-capable release," which is the event that starts the gate's soak clock. That PR merged today:

- **Default local worker pools to tmux** — [#2903](https://github.com/spinyfin/mono/pull/2903), merged `2026-09-04T19:11:26Z`.

Elapsed production exposure under the all-pool default at the time of this report is therefore **under a day**, not the seven consecutive days the gate requires. Rather than wait silently or relax the bar, this report records the gate as failed today, against the design's own instruction: "A failed criterion leaves the deletion tasks blocked and records the observed failure rather than relaxing the gate."

## Verdict

The gate fails on criteria #1, #2, #3, #5, and #10, and criteria #6–#8 cannot yet be evaluated for lack of elapsed exposure. Criterion #9 is met; criterion #4 has fixture-level evidence only, which the design explicitly does not accept as a substitute for the supported-driver drill.

Deletion work — starting with "Collapse local engine spawn and teardown to tmux only" — stays blocked. Re-running this gate is worthwhile no earlier than seven days after a rollout PR merge, and only once:

- the quit-dialog correction ([#2840](https://github.com/spinyfin/mono/pull/2840)) has merged or been forward-ported,
- a host capable of creating the isolated app's capture window has re-run the two supported-driver drills recorded in [tmux-recovery-validation-2026-09-04.md](./tmux-recovery-validation-2026-09-04.md) (restart, exit-status, controlled-recovery observations), and
- production execution volume and duplicate/token/session telemetry for the elapsed window can actually be pulled (forensic surfaces: `engine-audit.log`, `engine-trace.jsonl*`; see [forensic-surfaces.md](../forensic-surfaces.md)).

This report should be superseded by a later dated report once the soak window has actually elapsed, rather than edited in place.
