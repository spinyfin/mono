Bytes a raw-mode pane application receives for tmux send-keys, on the spike's tmux server
(tmux 3.8, Boss server options: extended-keys on, terminal-features xterm*:extkeys, focus-events on).
Keys sent, in order: C-m, Enter, Escape, literal 'a', C-c  (tools.py keyprobe)

  application sets no keyboard mode
      b'\r'
      b'\r'
      b'\x1b'
      b'a'
      b'\x03'

  application emits CSI > 4 ; 2 m  (xterm modifyOtherKeys mode 2) — agy emits this
      b'\x1b[27;5;109~'
      b'\r'
      b'\x1b'
      b'a'
      b'\x1b[27;5;99~'

  application emits CSI > 5 u  (kitty keyboard push) only
      b'\r'
      b'\r'
      b'\x1b'
      b'a'
      b'\x03'

  application emits both, as agy 1.5.5 does
      b'\x1b[27;5;109~'
      b'\r'
      b'\x1b'
      b'a'
      b'\x1b[27;5;99~'
